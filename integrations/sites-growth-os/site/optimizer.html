No GSC Wizard subscription

Connect the free Google updater.

Use your own Google Search Console access and a private Google Apps Script. The script reads Google, sends bounded reports to this dashboard and can refresh them daily while the website is closed.

  1. Verify Edelweizz in Google Search Console, using the Google account that will own the updater.
  2. Create a private Apps Script project. Copy the updater script and its manifest. Enable the Search Console API in the script's linked Google Cloud project.
  3. Set the script properties GSC_PROPERTY and EDELWEIZZ_SYNC_KEY. The property must be sc-domain:edelweizzindia.com or https://edelweizzindia.com/.
  4. Run syncEdelweizz, approve Google's read-only permission, then check for a successful receipt below. Run installDailyTrigger only after that succeeds.
